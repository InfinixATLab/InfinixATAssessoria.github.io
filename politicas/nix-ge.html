Política de Privacidade do App Nix - Gestão Empresarial

Última atualização: 08 de abril de 2026

Bem-vindo(a) ao Nix - Gestão Empresarial!

Esta Política de Privacidade descreve como a Infinix Tech Assessoria LTDA, inscrita no CNPJ nº 43.377.165/0001-90, trata os dados dos usuários ao utilizar nosso aplicativo ("App").

1. Finalidade do Aplicativo

O Nix - Gestão Empresarial é uma plataforma voltada para gestão eleitoral, destinada a candidatos, assessores e lideranças políticas, permitindo organização de dados, contatos e atividades de campanha.

2. Dados Coletados

Coletamos os seguintes dados fornecidos pelo usuário:

  • Nome
  • E-mail
  • Telefone / WhatsApp
  • RG ou CPF
  • Endereço
  • Data de nascimento
  • Dados políticos
  • Opiniões políticas

Também coletamos informações técnicas para segurança:

  • Identificação do dispositivo (para controle de login)

3. Dados Sensíveis

O App pode tratar dados sensíveis, como informações e opiniões políticas, exclusivamente para a finalidade de gestão eleitoral dentro da plataforma.

4. Uso de Localização

O aplicativo pode acessar a localização (GPS) do dispositivo de forma opcional, exclusivamente para exibir a posição atual do usuário no mapa.

Importante: esses dados não são armazenados em nossos servidores.

5. Uso dos Dados

Os dados coletados são utilizados para:

  • Funcionamento da plataforma
  • Organização de campanhas eleitorais
  • Autenticação e segurança de acesso

6. Armazenamento e Segurança

Os dados são armazenados em servidores seguros utilizando a plataforma Render.

  • Os dados são criptografados
  • As senhas são protegidas com padrão de segurança do Django
  • Autenticação via token (JWT)

Os dados são mantidos por um período de até 3 meses, podendo ser excluídos antes mediante solicitação do usuário.

7. Compartilhamento de Dados

Não compartilhamos dados pessoais com terceiros.

8. Serviços de Terceiros

O aplicativo utiliza serviços externos para funcionamento:

  • Google Maps (visualização de mapas)
  • WhatsApp (comunicação)

9. Controle de Acesso

O acesso ao aplicativo é feito por login e senha. Para maior segurança, o sistema pode restringir o uso a um único dispositivo por conta.

10. Direitos do Usuário (LGPD)

Nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/18), o usuário possui direito de:

  • Acessar seus dados
  • Corrigir informações
  • Excluir sua conta e todos os dados associados

11. Público-Alvo

O aplicativo é destinado a usuários com idade mínima de 16 anos.

12. Publicidade

O aplicativo não exibe anúncios e não realiza rastreamento para fins de marketing.

13. Alterações na Política

Esta Política de Privacidade pode ser atualizada periodicamente. Recomendamos a revisão regular desta página.
